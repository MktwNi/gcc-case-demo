# ระบบงานทวนสอบ GCC

- **ระบบใช้งานจริง:** https://mktwni.github.io/gcc-case-demo/app/
  - เข้าได้เฉพาะบัญชีที่ได้รับคำเชิญจาก GCC
  - ข้อมูลและไฟล์เก็บในฐานข้อมูลของ GCC แต่ละบทบาทเห็นและแก้ได้ตามสิทธิ์ที่ตั้งไว้
- **หน้าทดลอง:** https://mktwni.github.io/gcc-case-demo/
  - ข้อมูลทั้งหมดในหน้านี้เป็นข้อมูลสมมุติ อย่ากรอกข้อมูลหรือแนบไฟล์ของลูกค้าจริง
  - สิ่งที่กรอกและไฟล์ที่แนบเก็บไว้ในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ถูกส่งไปที่ใด
  - ถ้าต้องการล้างข้อมูลที่ลองไว้ทั้งหมด กดปุ่ม "เริ่มข้อมูลตัวอย่างใหม่" ที่แถบด้านบน
